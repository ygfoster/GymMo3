# GymMo3 設計メモ

GymMo2 を使い込んで出てきた不満（**探しにくさ・休憩タイマー・Fitbit データの見づらさ**）を起点に、同じデータ（GymMo2 と共有）の上に新しい画面を設計し直したもの。見た目は GymMo2 の Apple 風（モノクロの UI ＋ 意味を持つデータ色、ライト/ダーク自動追従）を引き継いで磨く。

## 設計の軸

| 不満 | GymMo2 でそうなっていた理由 | GymMo3 の答え |
| --- | --- | --- |
| 前回の重量・回数、部位ごとの最後の日、自己ベストが探しにくい | 「今日・履歴・分析」が**時間軸**で分かれ、1 つの種目の情報が 3 タブに散っていた | タブを**領域**で分ける: **トレーニング**（履歴・種目・自己ベストを 1 か所に）と**コンディション**（Fitbit を 1 か所に）。ホームは「今日の判断」に必要なものだけ |
| 休憩の時間調整が面倒 | 変更にはタイマー画面を開く必要があった | ドックの時間をタップすると、その場に **±10/±30 秒とテンプレート**が出る（画面を開かない）。種目ごとに**最後に使った休憩時間を記憶** |
| 残り時間が見づらい・終わったのに気づかない | ドックは記録画面の下端だけ。終了は 9 秒で勝手に待機へ戻る | **全画面の上端に進捗ライン**（どの画面でも見える）。残り 10 秒で時間表示が拡大して脈動。**終了は「次のセット」を押すまで消えない**。終了後も 20 秒ごとに振動で催促（設定でオフ可） |
| Fitbit の数字がすぐ読めない | 棒グラフ 3 本と PFC が同じカードに同居し、「それで今どうすべきか」が書かれていない | 用途で分ける: 朝=「**今日の調子**」（睡眠の大きな数字＋目標・週平均との差を一文で）／日中=「**食事の進み**」（タンパク質は「あと ◯ g」、カロリーは「あと ◯ kcal」）／週末=「**コンディション**」タブの週・月レビュー（目標達成日数、平均、トレーニング日との比較） |

## 画面構成（4 タブ ＋ 中央の記録ボタン）

```
[ホーム]  [トレーニング]  (●ダンベル)  [コンディション]      設定は ホーム右上の歯車
```

### ホーム（今日の判断に必要なものだけ）
1. **今日の調子**: 睡眠を主役に大きく表示。目標との差と、直近 7 日平均との差を一文で（例「7時間16分 ・ 目標達成 ・ 今週平均より +36分」）。下に 7 日分の小さな棒。
2. **食事の進み**: タンパク質「あと 68 g」（残りを主役に）、カロリー「あと 420 kcal」または「+120 kcal 超過」、PFC の割合バー。最終更新時刻つき。
3. **トレーニング**: 部位チップを「最後にやってから長い順」に並べ、先頭を**「次はこれ」**として前回のメニュー（種目名）を見せる。「同じメニューで始める」で記録画面に前回の種目を入れた状態で開く。今日すでに記録があればその内容と「続きを記録」。
4. **最近の自己ベスト**（直近 3 件）と **今週**（回数・セット数、先週比）。

### トレーニング（履歴と種目を 1 か所に）
- 上部の検索欄 1 つで、種目名・部位・メモ・日付を横断検索。
- セグメント **履歴 / 種目**。
  - 履歴: 月ごとのリスト（部位・種目名・PR バッジ）。カレンダー表示に切り替え可。
  - 種目: 部位ごとにグループ化。各行に「最終日・自己ベスト・直近 8 回の推移（ミニ折れ線）」。
- **種目の詳細**: 自己ベスト 4 種（推定 1RM・最高重量・最多回数・最大ボリューム）、推移グラフ（期間切替）、セッション一覧（セット内容つき）、「この種目を記録」。

### 記録（下から出るシート。GymMo2 の操作は維持しつつ補強）
- セット行の入力欄に**前回の値を薄く表示**（例 `50 × 11`）。タップでそのまま採用。2 セット目以降は 1 つ前のセットの値を既定に。
- ✓ で休憩タイマー自動開始（GymMo2 と同じ）。セットの左スワイプ削除も同じ。
- **休憩ドック**: 時間をタップ → その場に調整チップ（−30 / −10 / +10 / +30 ・ テンプレート）。残り 10 秒で時間が拡大・脈動。終了すると「次のセット」ボタンに変わり、押すまで消えない。
- 画面上端の**進捗ライン**は、記録シートを閉じても全画面で見える。

### コンディション（Fitbit を 1 か所に）
- セグメント **週 / 月**。
  - 週: 7 列 × 3 段（睡眠・タンパク質・カロリー収支）の棒。各段の右に平均と**目標達成日数**（例「睡眠 4/7 日」）。トレーニングした日に印。
  - 月: カレンダーのヒートマップ（指標をチップで切替）＋ 月の平均・達成率。
- **トレーニングとの関係**: トレーニング日と休息日の平均（睡眠・摂取・タンパク質）、睡眠とパフォーマンスの関係（GymMo2 の指標を流用）。
- 日をタップ → その日の詳細（睡眠・摂取/消費・PFC・その日のトレーニング）。

### 設定（歯車）
GymMo2 と同じ項目（外観、触覚・効果音、休憩タイマー、部位と休憩時間、テンプレート、目標、書き出し、接続）に加えて:
- 休憩終了後の**再通知**（20 秒ごと、オフ可）
- 種目ごとの休憩時間を記憶する（オン/オフ）

## データと基盤（GymMo2 と共有）

- **データは GymMo2 と同じ D1** を使う。どちらのアプリで記録しても両方に出る。シートへの自動コピー・毎時のヘルス取得は GymMo2 側の Worker がそのまま担当する。
- GymMo3 の Worker は **画面の配信**と、`/api` を GymMo2 の Worker へ**内部転送**（Service Binding。公開ネットを経由しない）するだけ。Google の秘密情報は GymMo3 側に持たない。
- 住所: `https://gymmo3.gymmo2.workers.dev/`（workers.dev のサブドメインはアカウント共通の `gymmo2`）。
- パスコードは GymMo2 と同じ。ワンタップ接続リンクも同じ仕組み。
- **Android アプリ**: GymMo2 のものを土台に、パッケージ `io.github.ygfoster.gymmo3`・名前・アイコン・読み込み先を変えて別アプリとして並べて入れられるようにする。通知のタイマーは同じ。
- コード: ビルド不要の ES Modules。日付・パース・指標・テンプレートなどの純粋ロジックは GymMo2 から流用し、画面は作り直す。
